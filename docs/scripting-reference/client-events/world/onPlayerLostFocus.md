# `event` onPlayerLostFocus <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when an entity loses focus.

## Parameters

```cpp
void onPlayerLostFocus(int id, string name)
```

* `int` **id**: Entity ID.
* `string` **name**: Entity name.
