# `event` onPlayerTakeFocus <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when an entity gains focus.

## Parameters

```cpp
void onPlayerTakeFocus(int id, string name, float x, float y, float z)
```

* `int` **id**: Entity ID.
* `string` **name**: Entity name.
* `float` **x**: X coordinate.
* `float` **y**: Y coordinate.
* `float` **z**: Z coordinate.
