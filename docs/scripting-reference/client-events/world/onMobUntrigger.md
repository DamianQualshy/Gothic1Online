# `event` onMobUntrigger <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when the player stops interacting with a mob.

## Parameters

```cpp
void onMobUntrigger(string name, float x, float y, float z, int type)
```

* `string` **name**: Entity name.
* `float` **x**: X coordinate.
* `float` **y**: Y coordinate.
* `float` **z**: Z coordinate.
* `int` **type**: Mob type.
