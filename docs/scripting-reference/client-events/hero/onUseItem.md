# `event` onUseItem <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when the player uses an item.

## Parameters

```cpp
void onUseItem(string instance, int amount, int hand)
```

* `string` **instance**: Item instance name.
* `int` **amount**: Item amount.
* `int` **hand**: Hand identifier.
