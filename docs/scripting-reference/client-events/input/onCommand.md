# `event` onCommand <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"
!!! tip "This event can be canceled"

This event is triggered when a script command is submitted.

## Parameters

```cpp
void onCommand(string command, string params)
```

* `string` **command**: Command name.
* `string` **params**: Command arguments.
