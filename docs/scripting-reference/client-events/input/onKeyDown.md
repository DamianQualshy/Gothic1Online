# `event` onKeyDown <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a keyboard key is pressed.

## Parameters

```cpp
void onKeyDown(int key, string letter)
```

* `int` **key**: Key code.
* `string` **letter**: Translated key character.
