# `event` onMouseDown <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a mouse button is pressed.

## Parameters

```cpp
void onMouseDown(int button)
```

* `int` **button**: Mouse button: `0` for left or `1` for right.
