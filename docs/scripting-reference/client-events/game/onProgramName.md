# `event` onProgramName <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a monitored program window is detected.

## Parameters

```cpp
void onProgramName(string windowText)
```

* `string` **windowText**: Detected window title.
