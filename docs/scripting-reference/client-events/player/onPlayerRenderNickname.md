# `event` onPlayerRenderNickname <font size="4">(client-side)</font>

!!! info "Available since version: 0.5.0"
!!! tip "This event can be canceled"

This event is triggered when a player nickname is rendered.

## Parameters

```cpp
void onPlayerRenderNickname(int id, string name, int x, int y)
```

* `int` **id**: Entity ID.
* `string` **name**: Entity name.
* `int` **x**: X coordinate.
* `int` **y**: Y coordinate.
