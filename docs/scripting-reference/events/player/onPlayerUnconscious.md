# `event` onPlayerUnconscious

!!! info "Available since version: 0.5.0"

This event is triggered when the player becomes unconscious.

## Parameters

```cpp
void onPlayerUnconscious(int playerID, int killerID)
```

* `int` **playerID**: Player ID.
* `int` **killerID**: Killer player ID.
