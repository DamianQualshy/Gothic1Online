# `event` onPlayerLostFocus

!!! info "Available since version: 0.5.0"

This event is triggered when an entity loses focus.

## Parameters

```cpp
void onPlayerLostFocus(int playerID, int focusID)
```

* `int` **playerID**: Player ID.
* `int` **focusID**: Focused entity ID.
