# `event` onPlayerTakeFocus

!!! info "Available since version: 0.5.0"

This event is triggered when an entity gains focus.

## Parameters

```cpp
void onPlayerTakeFocus(int playerID, int focusID)
```

* `int` **playerID**: Player ID.
* `int` **focusID**: Focused entity ID.
