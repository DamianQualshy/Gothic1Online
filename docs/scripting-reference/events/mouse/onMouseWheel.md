# `event` onMouseWheel

!!! info "Available since version: 0.5.0"

This event is triggered on the server when a connected client scrolls the mouse wheel.

## Parameters

```cpp
void onMouseWheel(int playerID, int delta)
```

* `int` **playerID**: Authenticated player ID.
* `int` **delta**: Mouse-wheel delta.
