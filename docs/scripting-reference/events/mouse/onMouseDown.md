# `event` onMouseDown

!!! info "Available since version: 0.5.0"

This event is triggered on the server when a connected client presses a mouse button.

## Parameters

```cpp
void onMouseDown(int playerID, int button)
```

* `int` **playerID**: Authenticated player ID.
* `int` **button**: Mouse button: `0` for left or `1` for right.
