# `function` setVobRotation <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets vob rotation.

## Declaration

```cpp
void setVobRotation(int vobID, float x, float y, float z)
```

## Parameters

* `int` **vobID**: Vob ID.
* `float` **x**: X coordinate.
* `float` **y**: Y coordinate.
* `float` **z**: Z coordinate.
