# `function` createVob <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function creates vob.

## Declaration

```cpp
int createVob(string visual, float x, float y, float z, float rotx, float roty, float rotz)
```

## Parameters

* `string` **visual**: Visual.
* `float` **x**: X coordinate.
* `float` **y**: Y coordinate.
* `float` **z**: Z coordinate.
* `float` **rotx**: Rotx.
* `float` **roty**: Roty.
* `float` **rotz**: Rotz.

## Returns `int`

Identifier of the created object.
