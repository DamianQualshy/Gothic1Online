# `function` setVobCollision <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets vob collision.

## Declaration

```cpp
void setVobCollision(int vobID, bool enable)
```

## Parameters

* `int` **vobID**: Vob ID.
* `bool` **enable**: True to enable the feature, false to disable it.
