# `function` disableKey <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function enables or disables a Gothic input key.

## Declaration

```cpp
void disableKey(int key, bool toggle)
```

## Parameters

* `int` **key**: Gothic input key code.
* `bool` **toggle**: True to enable the feature, false to disable it.
