# `function` giveItem <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function adds an item to the local player's inventory.

## Declaration

```cpp
void giveItem(string instance, int amount)
```

## Parameters

* `string` **instance**: Item instance name.
* `int` **amount**: Item amount.
