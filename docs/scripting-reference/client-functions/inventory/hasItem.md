# `function` hasItem <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function checks whether the player has item.

## Declaration

```cpp
int hasItem(string instance)
```

## Parameters

* `string` **instance**: Item instance name.

## Returns `int`

True if the player has item, otherwise false.
