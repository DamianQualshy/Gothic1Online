# `function` md5File <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function calculates the MD5 digest of a file.

## Declaration

```cpp
string md5File(string filename)
```

## Parameters

* `string` **filename**: Path to the file.

## Returns `string`

Lowercase hexadecimal MD5 digest.
