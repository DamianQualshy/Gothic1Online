# `function` createDraw <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function creates draw.

## Declaration

```cpp
int createDraw(string text, string font, int x, int y, int r, int g, int b)
```

## Parameters

* `string` **text**: Text.
* `string` **font**: Font.
* `int` **x**: X coordinate.
* `int` **y**: Y coordinate.
* `int` **r**: Red color component.
* `int` **g**: Green color component.
* `int` **b**: Blue color component.

## Returns `int`

Identifier of the created object.
