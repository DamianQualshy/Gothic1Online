# `function` setDrawColor <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets draw color.

## Declaration

```cpp
void setDrawColor(int drawID, int r, int g, int b)
```

## Parameters

* `int` **drawID**: Draw ID.
* `int` **r**: Red color component.
* `int` **g**: Green color component.
* `int` **b**: Blue color component.
