# `function` setDrawVisible <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets draw visible.

## Declaration

```cpp
void setDrawVisible(int drawID, bool enable)
```

## Parameters

* `int` **drawID**: Draw ID.
* `bool` **enable**: True to enable the feature, false to disable it.
