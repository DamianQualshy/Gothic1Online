# `function` setTexturePosition <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets texture position.

## Declaration

```cpp
void setTexturePosition(int texID, int x, int y)
```

## Parameters

* `int` **texID**: Tex id.
* `int` **x**: X coordinate.
* `int` **y**: Y coordinate.
