# `function` setTextureSize <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets texture size.

## Declaration

```cpp
void setTextureSize(int texID, int w, int h)
```

## Parameters

* `int` **texID**: Tex id.
* `int` **w**: Width.
* `int` **h**: Height.
