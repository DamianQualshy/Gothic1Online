# `function` setDrawPosition <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets draw position.

## Declaration

```cpp
void setDrawPosition(int drawID, int x, int y)
```

## Parameters

* `int` **drawID**: Draw ID.
* `int` **x**: X coordinate.
* `int` **y**: Y coordinate.
