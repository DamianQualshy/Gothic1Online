# `function` createTexture <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function creates texture.

## Declaration

```cpp
int createTexture(int x, int y, int w, int h, string textureString)
```

## Parameters

* `int` **x**: X coordinate.
* `int` **y**: Y coordinate.
* `int` **w**: Width.
* `int` **h**: Height.
* `string` **textureString**: Texture string.

## Returns `int`

Identifier of the created object.
