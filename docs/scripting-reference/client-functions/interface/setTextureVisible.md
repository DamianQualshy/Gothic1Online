# `function` setTextureVisible <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function sets texture visible.

## Declaration

```cpp
void setTextureVisible(int texID, bool enable)
```

## Parameters

* `int` **texID**: Tex id.
* `bool` **enable**: True to enable the feature, false to disable it.
