# `function` setPlayerStatusVisible <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function shows or hides player status.

## Declaration

```cpp
void setPlayerStatusVisible(bool enable)
```

## Parameters

* `bool` **enable**: True to enable the feature, false to disable it.
