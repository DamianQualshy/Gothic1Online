# `function` setMarvinEnabled <font size="4">(client-side)</font>

!!! info "Available since version: 0.4.0"

This function enables or disables marvin.

## Declaration

```cpp
void setMarvinEnabled(bool enable)
```

## Parameters

* `bool` **enable**: True to enable the feature, false to disable it.
