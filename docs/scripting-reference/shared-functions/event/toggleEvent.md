# `function` toggleEvent <font size="4">(shared-side)</font>

!!! info "Available since version: 0.5.0"

This function enables or disables an event globally.

## Declaration

```cpp
void toggleEvent(string eventName, bool enabled)
```

## Parameters

* `string` **eventName**: Event name.
* `bool` **enabled**: Whether the event is enabled.
