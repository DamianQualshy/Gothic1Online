# `function` getDistance3d <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function calculates the distance between two 3D points.

## Declaration

```cpp
float getDistance3d(float x1, float y1, float z1, float x2, float y2, float z2)
```

## Parameters

* `float` **x1**: First X coordinate.
* `float` **y1**: First Y coordinate.
* `float` **z1**: First Z coordinate.
* `float` **x2**: Second X coordinate.
* `float` **y2**: Second Y coordinate.
* `float` **z2**: Second Z coordinate.

## Returns `float`

Distance between the points.
