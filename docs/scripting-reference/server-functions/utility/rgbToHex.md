# `function` rgbToHex <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function converts RGB color components to a hexadecimal string.

## Declaration

```cpp
string rgbToHex(int red, int green, int blue)
```

## Parameters

* `int` **red**: Red component.
* `int` **green**: Green component.
* `int` **blue**: Blue component.

## Returns `string`

Six-character hexadecimal color.
