# `function` hexToRgb <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function converts a hexadecimal color to RGB components.

## Declaration

```cpp
table hexToRgb(string color)
```

## Parameters

* `string` **color**: Hexadecimal color, with or without a leading `#`.

## Returns `table`

Table containing `r`, `g`, and `b` components.
