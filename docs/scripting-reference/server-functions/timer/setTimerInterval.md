# `function` setTimerInterval <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function changes a script timer's interval.

## Declaration

```cpp
bool setTimerInterval(int timerId, int interval)
```

## Parameters

* `int` **timerId**: Timer ID.
* `int` **interval**: Interval in milliseconds.

## Returns `bool`

True if the timer was updated.
