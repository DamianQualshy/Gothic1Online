# `function` killTimer <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function stops and removes a script timer.

## Declaration

```cpp
bool killTimer(int timerId)
```

## Parameters

* `int` **timerId**: Timer ID.

## Returns `bool`

True if the timer was removed.
