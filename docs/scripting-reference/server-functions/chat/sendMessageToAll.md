# `function` sendMessageToAll <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function sends message to all.

## Declaration

```cpp
void sendMessageToAll(int r, int g, int b, string message)
```

## Parameters

* `int` **r**: Red color component.
* `int` **g**: Green color component.
* `int` **b**: Blue color component.
* `string` **message**: Message text.
