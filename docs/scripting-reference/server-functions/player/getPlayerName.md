# `function` getPlayerName <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function returns player name.

## Declaration

```cpp
string getPlayerName(int playerID)
```

## Parameters

* `int` **playerID**: Player ID.

## Returns `string`

Player name, or `NULL` when the player does not exist.
