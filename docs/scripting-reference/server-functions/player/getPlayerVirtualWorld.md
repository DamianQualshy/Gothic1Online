# `function` getPlayerVirtualWorld <font size="4">(server-side)</font>

!!! info "Available since version: 0.4.0"

This function returns player virtual world.

## Declaration

```cpp
int getPlayerVirtualWorld(int playerID)
```

## Parameters

* `int` **playerID**: Player ID.

## Returns `int`

Virtual-world ID, or -1 if the player does not exist.
