# `event` onPlayerDisconnect <font size="4">(server-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a player disconnects from the server.

## Parameters

```cpp
void onPlayerDisconnect(int playerID, string reason)
```

* `int` **playerID**: Player ID.
* `string` **reason**: Disconnect reason.
