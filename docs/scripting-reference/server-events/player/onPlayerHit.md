# `event` onPlayerHit <font size="4">(server-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a hit occurs.

## Parameters

```cpp
void onPlayerHit(int playerID, int targetID)
```

* `int` **playerID**: Player ID.
* `int` **targetID**: Target player ID.
