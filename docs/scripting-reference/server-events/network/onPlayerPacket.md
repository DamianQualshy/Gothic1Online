# `event` onPlayerPacket <font size="4">(server-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when a script packet is received.

## Parameters

```cpp
void onPlayerPacket(int playerID, string data)
```

* `int` **playerID**: Player ID.
* `string` **data**: Packet data.
