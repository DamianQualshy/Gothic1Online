# `event` onAdminCommand <font size="4">(server-side)</font>

!!! info "Available since version: 0.5.0"

This event is triggered when an administrator command is submitted.

## Parameters

```cpp
void onAdminCommand(int playerID, string command)
```

* `int` **playerID**: Player ID.
* `string` **command**: Command name.
