# `function` getDistance2d

!!! info "Available since version: 0.4.0"

This function calculates the distance between two 2D points.

## Declaration

```cpp
float getDistance2d(float x1, float y1, float x2, float y2)
```

## Parameters

* `float` **x1**: First X coordinate.
* `float` **y1**: First Y coordinate.
* `float` **x2**: Second X coordinate.
* `float` **y2**: Second Y coordinate.

## Returns `float`

Distance between the points.
