# `function` createGroundItem

!!! info "Available since version: 0.4.0"

This function creates item.

## Declaration

```cpp
int createGroundItem(string itemInstance, int amount, float x, float y, float z, string world)
```

## Parameters

* `string` **itemInstance**: Item instance.
* `int` **amount**: Item amount.
* `float` **x**: X coordinate.
* `float` **y**: Y coordinate.
* `float` **z**: Z coordinate.
* `string` **world**: World name.

## Returns `int`

Identifier of the created object.
