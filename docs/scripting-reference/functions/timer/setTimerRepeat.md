# `function` setTimerRepeat

!!! info "Available since version: 0.4.0"

This function changes whether a script timer repeats.

## Declaration

```cpp
bool setTimerRepeat(int timerId, bool repeat)
```

## Parameters

* `int` **timerId**: Timer ID.
* `bool` **repeat**: Whether the timer repeats.

## Returns `bool`

True if the timer was updated.
