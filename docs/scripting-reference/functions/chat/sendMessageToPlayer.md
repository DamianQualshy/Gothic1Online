# `function` sendMessageToPlayer

!!! info "Available since version: 0.4.0"

This function sends message.

## Declaration

```cpp
void sendMessageToPlayer(int playerID, int r, int g, int b, string message)
```

## Parameters

* `int` **playerID**: Player ID.
* `int` **r**: Red color component.
* `int` **g**: Green color component.
* `int` **b**: Blue color component.
* `string` **message**: Message text.
